# AI tools used

| Tool | What it was used for |
|---|---|
| **Claude Code** (Anthropic, model Claude Opus 5.5) | I gave it the brief and a detailed prompt of my own (requirements and constraints). It inspected the workspace, proposed the design, and wrote the code, tests, generator, evaluator and docs. It ran the test suite and the end-to-end checks, and verified the research citations with web search. It also found and fixed two bugs during testing: a missed shock phrasing, and a 500 error on `NaN` input. At my request it ran a 14-case challenge in unseen styles, then fixed the 3 misses (a misspelling, a Hinglish shock phrase, and the `OOW` abbreviation) using offline word and phrase lists, adding regression and near-miss tests. At my request it also wrote TESTING.md (test plan, traceability, catalogue, defect log), the script that fills in its results from a real pytest run, and the GitHub Actions CI workflow. Later, at my request, it added `run.ps1` for Windows, a Playwright browser-test suite (Chromium, Firefox, WebKit) with an axe-core audit and screen-reader name and role checks, and CI on Linux, macOS and Windows. That work found and fixed four more defects (TESTING.md DEF-11 to DEF-14). A real screen-reader session has not been run; the manual checklist in TESTING.md §3b is recorded as NOT RUN. When the Windows start-up check hung, Claude Code diagnosed it on a real Windows runner with a temporary probe workflow. That found two root causes: Windows runners kill a step's processes when the step ends, and pydantic 2.10 has no Python 3.14 wheel. It fixed them with a single-process smoke check, newer pins and Python 3.14 in CI (TESTING.md DEF-15 to DEF-19). |
| **UI UX Pro Max** (Claude Code skill, local search over UI/UX guidance) | Ran its design-system search ("enterprise internal tool service agent form") and a UX search on inline validation. The page uses its Swiss-minimal style, navy/blue palette, visible focus states, per-field errors linked by `aria-describedby`, a focusable error summary and the reduced-motion rule. Two suggestions were not used: Google Fonts and GSAP, because the page must load nothing from the network. I later asked Claude Code to restyle the page as an agent-assist style service workspace (case intake, recommendation card, decision path, policy checks, copyable case note). It took the workflow pattern only; no vendor branding is used. In a later polish pass I used the skill's UX searches again (type scale, focus visibility, keyboard order, "never colour alone"). Design decisions from that pass: (1) a token-based Swiss-minimal system with a 4-pt spacing scale and a fixed type scale, fewer borders, with sections separated by spacing and hairlines; (2) hierarchy: the recommended action is the largest element (36 px, colour plus icon plus text label), then the repair-cost estimate and a cost-vs-replacement bar marking the deciding rule's limit; (3) the full D0 formula shown line by line from the engine's own values, so the 600 travel component of C-2001 (40 min ÷ 60 × 900) is visible, with no invented costs; (4) the decision path as a vertical sequence with a plain sentence per stage, and the full policy checks behind a disclosure; (5) confidence labelled a heuristic, not a calibrated probability, with its line-by-line basis; (6) input borders darkened to 3.06:1 after a contrast check (WCAG 1.4.11). The skill suggested Inter and Plus Jakarta Sans; I kept the system font stack because remote fonts are not allowed. |
| **VibeWise** (Claude Code plugin) | Not used to build the project. It was installed during the session but could not be loaded until Claude Code restarted, and its `learn` command can only be started by the user. I plan to use it afterwards to study the code; if I do, I will add that here. |

No AI service is called by the running application. Decisions come from the rules in `app/policy.py`.

I have reviewed the code and can explain it; [EXPLANATION.md](EXPLANATION.md) is my study guide. The choices listed in NOTES.md (null travel, the missing-data rule, threshold inclusivity, the confidence heuristic) were made deliberately, and each one is covered by tests.
